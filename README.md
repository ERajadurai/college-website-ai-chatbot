# College Website AI Chatbot using Django

## 📌 Project Overview

This project is a **Django-based college website integrated with an AI-powered chatbot** designed to assist students, faculty, and visitors by providing instant responses to common queries.

The system enhances user experience by automating information delivery such as admissions, courses, events, and general inquiries. The chatbot reduces manual effort and improves accessibility of information through a simple and interactive interface.

---

## 🎯 Objective

* Develop a dynamic college website using Django
* Integrate an AI chatbot for automated query handling
* Provide real-time responses to user questions
* Improve user engagement and reduce administrative workload

---

## 🛠️ Technologies Used

* Python
* Django (Web Framework)

## ▶️ How to Run

1. Clone the repository
2. Navigate to the project folder
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the server:

```bash
python manage.py runserver
```

5. Open browser and visit:

```text
http://127.0.0.1:8000/
```

---

## ⚠️ Note

The virtual environment (`venv`) is excluded from the repository. Install required packages using the provided `requirements.txt`.
